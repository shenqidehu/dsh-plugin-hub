# 插件中心（dsh-plugin-hub）

自制插件的统一入口面板。侧边栏固定一个图标，点开后是一页「插件中心」：左边列出所有接入的插件，右边是它自己的使用页与设置页。

## 能做什么

- **一个固定入口**：`sidebar.panellist` 的 `order` 为 1，排在「插件」「市场」等内置面板之前，桌面端展开侧边栏、手机端展开抽屉都能看到。
- **自动发现**：面板启动时枚举 `plugin-hub.usage` 与 `plugin-hub.settings` 两个子槽位的注册项，按 `order` 排序生成左侧导航；插件注册/卸载时实时增删，无需重启。
- **使用页与设置页分开**：同一插件可分别提供两页，面板顶部自动出现「使用 / 设置」页签；只提供其中一页时页签自动隐藏。
- **记忆位置**：上次打开的插件与页签存在浏览器 `localStorage`（键 `dsh-plugin-hub:view`），重开面板回到原位。
- **双端同一份代码**：电脑端 DSH 与手机端 DSH Go 安装同一个包，窄屏（≤720px）自动把左侧导航折成顶部横向条。

## 怎么用

1. 在插件管理器里安装并启用 `dsh-plugin-hub`。
2. 侧边栏出现「插件中心」图标，点击进入。
3. 自制插件按 `README.md` 里的三行模板接入后，会出现在左侧列表。

## 限制

- 面板只负责**收集与展示**，插件页面的数据读写仍由各插件自己的 Host 路由或工具完成。
- 插件的页面组件必须注册到 `plugin-hub.usage` / `plugin-hub.settings`；没有注册的插件不会出现在导航里（面板不会去扫描插件包）。
- 页面根元素需自带内边距（面板的内容区不提供 padding），否则内容会贴边。
- 面板不代理任何第三方插件；第三方插件若要进入面板，需要额外写一层适配注册（见 `README.md` 的「移植第三方插件」一节）。
